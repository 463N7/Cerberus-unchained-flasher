CERBERUS UNCHAINED / REV144

Upload when you choose.

Stop recording, then open Scan → Wardriving → LOGS / UPLOAD. Uploads use your home Wi-Fi and need your action and service credentials. Saving or importing settings does not connect or upload.

Experimental release: WiGLE has acknowledged an upload, but account processing and credit need separate confirmation. The last WDGWars attempt failed during its TLS handshake. Live Wardrift uploads remain unverified.

Import your settings from SD

  1. Download the empty upload profile. Fill a private copy on your computer. Keep all sections and field names exactly as supplied.
  2. Enter your home Wi-Fi ssid and password. The access point must offer 2.4 GHz. A blank password means an open network. Enterprise authentication and captive-portal sign-in are not supported.
  3. For each service you want to use, enter its credentials and change enabled to true. Leave unused services empty and disabled. WiGLE needs both api_name and api_token; WDGWars needs a 64-character hexadecimal token; Wardrift needs its device/API token.
  4. Save as UTF-8 without a byte-order mark, named UPLOAD.JSON, and copy to CERBERUS/CONFIG/UPLOAD.JSON on the SD card. Create CONFIG if needed. Safely eject the card or USB drive and return SD ownership to Cerberus.
  5. Open LOGS / UPLOAD → HOME WI-FI / API SETUP → IMPORT JSON FROM SD. Review the notice, then choose CONFIRM IMPORT. This replaces the whole saved profile, including empty and disabled fields.
  6. Wait for PROFILE SAVED / SD COPY REMOVED, then reopen setup and check its SET/EMPTY labels and enabled destinations. If the SD copy remains, check setup and remove that file yourself. File removal is not a secure erase.

Keep your completed profile private. Never share it in a report or issue. The device verifies saved settings before removing the SD copy. An invalid profile leaves saved settings unchanged.

All fields are required, with no comments, duplicate or unknown keys. The maximum file size is 4,096 bytes. Limits in UTF-8 bytes: SSID 32, password 64, WiGLE API name 64, WiGLE token 128, Wardrift token 128; a supplied WDGWars token must be exactly 64 hexadecimal characters.

Or enter settings on Cerberus

Open LOGS / UPLOAD → HOME WI-FI / API SETUP. Enter the home network and keys, turn on the desired destinations, then choose SAVE SETUP. The keyboard enters ASCII; the JSON profile supports UTF-8 network names.

Get WiGLE's API name and token from its API account page, rather than using your normal account password. Get WDGWars's API key from your provider profile; see its developer guide. Wardrift integration is provisional and still needs live account verification.

Passwords and keys are masked with an explicit reveal control. This firmware does not enable encrypted credential storage; someone with physical access can expose saved credentials. FORGET HOME AP AND ALL KEYS removes the upload profile after confirmation and keeps captures and receipts.

Record and select a log

Before START, wait for GPS DATA > FIX + UTC / WIGLE CSV. During recording, check that SD: … ROWS increases. Stop and wait for CSV SAVED / OPEN LOGS BELOW.

Rev144 saves one WiGLE 1.6 file per session, such as CERBERUS/WARD/CERBWardrive001.CSV, preserving repeated valid sightings. Scanning can run without GPS, but no CSV row is saved without valid position and UTC. If no eligible rows were saved, STOPPED / NO CSV SAVED explains why. A scan alone does not mean a file was recorded.

Open LOGS / UPLOAD and review a file's rows and status. Legacy unlocated logs stay local and cannot upload. Malformed files need review on a computer; the device does not silently rewrite them.

Send, check results and retry

Choose UPLOAD THIS LOG or UPLOAD ALL LOCATED LOGS. Review the files, selected services and disclosure of locations and identifiers, then choose CONFIRM UPLOAD. Upload keeps the original CSV. Cancel stops further work; pending network operations may take their timeout to finish.

NOT SENT
No matching confirmed receipt exists for these contents and credentials.
IN PROGRESS / INCOMPLETE
Only some parts have been acknowledged. The complete file has not been confirmed.
UPLOADED
Every part has a confirmed service receipt. Processing, import and account credit are separate; check the provider account.
REJECTED
The service explicitly rejected the request. Correct its cause before manually retrying.
CHECK ACCOUNT
Delivery is uncertain, or the saved receipt needs review. Check the provider account before resending.

Reopen a log to see its saved receipts. Later uploads skip parts already acknowledged for the same contents and credentials. Rotating a key creates a new receipt identity, so check your account before uploading old captures again.

For an uncertain service, use its RETRY … UPLOAD or REVIEW RETRY action, review the scope and choose CONFIRM SERVICE RETRY. An earlier attempt may already have arrived, so this can resubmit data. Other services and acknowledged parts are not resent. There is no automatic resend or account-status reconciliation.

Deletion is a separate confirmed action and cannot be undone. It excludes temporary captures, unrelated folders, credentials and receipts.
